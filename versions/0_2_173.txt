1) Update shared package version

Use shared version that includes `MapLocationPicker` form-style onChange support.

2) Update consumer usage in forms

Example file:
  src/custom_components/admin/Venues/ManageVenueForm.tsx

Replace this pattern:

OLD:
```tsx
<MapLocationPicker
  label={t("venueLocation")}
  value={geoPointValue}
  onChange={(location: MapLocationValue): void => {
    handleInputChange({
      target: {
        name: "geoPoint",
        value: location,
        type: "text",
        checked: false,

  error={errors.geoPoint}
  disabled={inProgress}
  defaultZoom={12}
```

```tsx
<MapLocationPicker
```
