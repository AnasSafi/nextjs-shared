UPGRADE GUIDE - Shared Package v0.2.29

Goal:
Move CTextArea into @nextjs-shared/shared.
CTextArea preserves per-locale internal state and direction logic, but now requires injected deps for multi-locale behavior:
- t is optional (used for required tooltip)
- languages is optional (used for RTL fallback based on locale)

1) Update dependency
OLD: "@nextjs-shared/shared": "^0.2.28"
NEW: "@nextjs-shared/shared": "^0.2.29"
Run: npm install

2) Replace imports
OLD:
import CTextArea from "@/components/Form/CTextArea";

NEW:
import {CTextArea} from "@nextjs-shared/shared";

3) When using multi-locale behavior (toggleLocale/formLocale or locale initValue object), pass t and languages
Example:
import {CTextArea} from "@nextjs-shared/shared";
import {useTranslation} from "@/app/i18n/client_translation";
import {languages} from "@/config/localizationConfig";

const {t} = useTranslation();

<CTextArea
  t={t}
  languages={languages}
  name="..."
  label="..."
  formLocale={formLocale}
  toggleLocale={toggle}
/>

4) Optional wrapper
If you want to keep old import path, create a local wrapper that injects t and languages.

Final checks:
- Shared build passes
- Consumer build passes
- Shared CTextArea contains no "@/..." imports
