UPGRADE GUIDE - Shared Package v0.2.25

Goal:
- isLocaleObject moved to shared.
- CInput moved to shared and now accepts optional props:
  - t?: (key: string) => string
  - languages?: LanguageConfig[]
languages is only needed for multi-language behavior (stacked locale view and RTL detection).

1) Update dependency
OLD: "@nextjs-shared/shared": "^0.2.24"
NEW: "@nextjs-shared/shared": "^0.2.25"
Run: npm install

2) Use CInput from shared
Example:
import {CInput} from "@nextjs-shared/shared";

If you need required tooltip and/or multi-language behavior:
import {useTranslation} from "@/app/i18n/client_translation";
import {languages} from "@/config/localizationConfig";

const {t} = useTranslation();

<CInput
  t={t}
  languages={languages}
  name="..."
  label="..."
/>

3) Optional wrapper
If you want to keep old project import path "@/components/Form/CInput", you can create a local wrapper that injects t and languages.

Final checks:
- Shared build passes
- Consumer build passes
- Shared CInput contains no "@/..." imports
