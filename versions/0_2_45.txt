Project to give this task to:
Consumer app (e.g. club_next_js)

Goal:
- Stop duplicating shared models locally.
- Import dbModels/formModels/mediaModels/userModels directly from @nextjs-shared/shared.
- Keep ONLY Prisma + react-hook-form dependent bridging types inside the consumer.

------------------------------------------------------------
1) Replace local userModels with a thin bridge
------------------------------------------------------------

File to update:
src/models/user/userModels.ts

OLD CODE TO DELETE:
Delete the entire current content of src/models/user/userModels.ts
(the file that contains all the interfaces/classes: UserModel, User, etc.)

NEW CODE (FULL FILE – COPY/PASTE):

    LoginResponseOptionsModelsBase,
    ResetPasswordCodeRequestModelBase
