Goal:

- Add keys only if they are missing.

Context:
- Shared modal now uses translation keys (instead of hardcoded English) for unsaved-changes confirmation.
- Newly expected keys:
  - `unsavedChangesTitle`
  - `unsavedChangesMessage`
- Existing/common keys usually already present:
  - `close`
  - `cancel`

1) Inspect consumer translation files

Check all locale dictionaries used by your app (for example: `en`, `ar`, etc.) and verify whether:
- `unsavedChangesTitle`
- `unsavedChangesMessage`
already exist.

If key is missing in a locale, add it.

3) Keep existing `close` and `cancel`

Do not rename/remove existing keys.
`ModalTemplateCore` uses:
- `close` for confirm-close button text
- `cancel` for keep-editing button text

4) Verify

- Open any modal form that can become dirty.
- Press `Esc` when form has unsaved changes.
- Confirm dialog should display translated:
  - title (`unsavedChangesTitle`)
  - message (`unsavedChangesMessage`)
  - buttons (`close`, `cancel`)
