UPGRADE GUIDE — Shared Package v0.2.9

Goal:
Remove the local ErrorAlert component from consumer projects and use the shared ErrorAlert component directly.
The shared ErrorAlert requires passing the translation function `t` from the project.

--------------------------------------------------------------------
1) Delete the local component file (must be removed)

Delete this file from the consumer project:
src/components/Alert/ErrorAlert.tsx

--------------------------------------------------------------------
2) Replace all imports and usages across the project

1) Replace imports

OLD CODE TO DELETE:
import ErrorAlert from "@/components/Alert/ErrorAlert";

NEW CODE TO ADD:
import {ErrorAlert} from "@nextjs-shared/shared";

2) Ensure `t` is always passed

Example replacement pattern:

OLD CODE TO DELETE:
<ErrorAlert titleKey="SOME_KEY" messageKey="SOME_KEY" />

NEW CODE TO ADD:
const {t} = useTranslation();
<ErrorAlert t={t} titleKey="SOME_KEY" messageKey="SOME_KEY" />

If the file does not already have the translation hook, add it:

OLD CODE TO DELETE (if missing):
// no useTranslation import

NEW CODE TO ADD:
import {useTranslation} from "@/app/i18n/client_translation";

Then inside the component:
const {t} = useTranslation();

Finally pass t:
<ErrorAlert t={t} ... />

--------------------------------------------------------------------
3) Notes / Rules

- The shared ErrorAlert must remain generic and must NOT import from any project path (no "@/..." imports).
- Consumers are responsible for providing `t` (translation function) from their own i18n setup.
- After migration, there must be no remaining references to "@/components/Alert/ErrorAlert".
